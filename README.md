# GraphicEditor

Простой графический редактор на C# с использованием WPF. Проект выполнен в рамках лабораторной работы по объектно-ориентированному программированию.

## Возможности

- Рисование карандашом.
- Создание прямых линий, прямоугольников и эллипсов.
- Выбор цвета и толщины линий.
- Предварительный просмотр фигур во время рисования.
- Очистка холста.
- Сохранение изображения в PNG.

## Технологии

- C#
- .NET 10
- WPF

## Структура проекта

- `Tools` — классы инструментов рисования.
- `Services` — управление инструментами и сохранение изображений.
- `MainWindow.xaml` — интерфейс приложения.
- `MainWindow.xaml.cs` — обработка действий пользователя.

Для запуска проекта необходимо открыть GraphicEditor.sln в совместимой среде разработки, например JetBrains Rider или Visual Studio, и запустить приложение.
