# GraphicEditor — графический редактор на C# / WPF

Учебная лабораторная по ООП. Реализовано на .NET 10 (Windows), без сторонних библиотек.

## Как запустить

1. Откройте `GraphicEditor.sln` в JetBrains Rider на Windows.
2. Убедитесь, что установлен .NET 10 SDK.
3. Запустите проект `GraphicEditor`.

## Возможности

- Карандаш (свободное рисование при удержании ЛКМ).
- Прямые линии, прямоугольники, эллипсы, включая предпросмотр при движении мыши.
- Готовая палитра цветов и возможность ввести любой HEX-цвет вида `#RRGGBB`.
- Толщина от 1 до 20 пикселей.
- Обрезка рисования по границам холста.
- Очистка холста.
- Экспорт рисунка в PNG с выбором пути и имени файла.

## Архитектура

- `Tools/DrawingTool.cs` — абстрактный базовый класс с методами `OnMouseDown`, `OnMouseMove`, `OnMouseUp`.
- `Tools/PencilTool.cs`, `LineTool.cs`, `RectangleTool.cs`, `EllipseTool.cs` — наследники, переопределяющие все методы рисования.
- `Services/ToolManager.cs` — хранит активный инструмент и передаёт ему события полиморфно, без проверок типа инструмента.
- `Services/ImageExportService.cs` — сохраняет содержимое WPF Canvas в PNG.
- `MainWindow.xaml` — разметка интерфейса; `MainWindow.xaml.cs` — обработчики событий и связь компонентов.

## Быстрая проверка

1. Нарисуйте свободную линию карандашом.
2. Проверьте предпросмотр прямой, прямоугольника и эллипса при перетаскивании.
3. Выберите другой цвет и толщину; старые фигуры должны остаться без изменений.
4. Нарисуйте фигуру справа налево и за границей холста.
5. Сохраните PNG и откройте файл.
6. Очистите холст.

Проект предназначен для Windows: WPF не запускается в Linux или macOS.
